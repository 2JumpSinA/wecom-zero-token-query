# 04 · 常驻与防闪窗

## 为什么必须常驻

智能机器人是**本机主动连出去**的长连接。进程不在，消息就没人接 —— 企微没有"来消息再唤醒你本机程序"的能力
（回调模式要公网入口，本方案不走那条路）。所以"有个进程一直挂着"是必须的。

但**"每分钟跑一个计划任务"不是必须的**，那只是自愈手段。三档可选：

| 档 | 做法 | 崩了怎么办 | 打扰 |
|---|---|---|---|
| A | 只在登录时启动（启动文件夹 + `start-hidden.vbs`） | 手动双击拉起 | 无 |
| **B（推荐）** | 登录启动 + 每分钟静默体检（本 skill 默认） | 最多 1 分钟自动拉起 | 无（已防闪窗） |
| C | 把体检并进已有的常驻看门狗进程 | 自动拉起 | 无（但与那个进程耦合） |

## 注册计划任务（必须走 wscript）

```cmd
schtasks /create /tn WecomFastlane /tr "wscript.exe //nologo D:\wecom-fastlane\watchdog-hidden.vbs" /sc minute /mo 1 /f /rl LIMITED
schtasks /run /tn WecomFastlane
```

**为什么是 wscript 而不是 powershell.exe**：
Task Scheduler 拉起 `powershell.exe`（控制台程序）时，**控制台窗口先被创建**，
`-WindowStyle Hidden` 只是随后把它藏起来 —— 于是**每分钟屏幕闪一下**。
`wscript.exe` 是 GUI 子系统程序，**根本不创建控制台**；再由它用窗口样式 0 拉起 PowerShell 并等它结束，
这样 `LastTaskResult` 仍然是真实退出码（不是恒为 0 的假数字）。

```vbs
' watchdog-hidden.vbs：隐藏拉起 + 等待并透传退出码
rc = sh.Run("powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File " & q & root & "\fastlane-watchdog.ps1" & q, 0, True)
WScript.Quit rc
```

## 看门狗的健康判据（三个条件同时成立）

短命检查（每次跑完就退出，不是常驻循环 → 没有互斥量可泄漏、没有 `AbandonedMutexException` 那类坑）：

1. **进程在**：优先读 `logs\fastlane.pid`（守护进程自己写的 PID），并用命令行锚定校验
2. **心跳新鲜**：`logs\heartbeat.txt` 在 4 分钟内
3. **心跳里的 pid 等于该进程**：`heartbeat.txt` 内容形如 `2026-09-19T04:41:45Z pid=17672 alive`

任一条不成立 → 杀掉旧进程（如果还活着）→ 通过 `start-hidden.vbs` 起一个新的。

### 为什么必须锚定命令行 + 带 pid（两条都是血的教训）

- **锚定**：筛选条件写成"命令行含 `fastlane.mjs` 的 node 进程"是**错的** ——
  `--selftest` / `--check` 的命令行里同样含这个字符串；更糟的是，agent 运行器自己执行我们的命令时，
  它的命令行里**引用了这段筛选文本本身**，于是被一起匹配到 —— 杀掉它等于把 agent 运行器打掉。
  正确写法：`fastlane\.mjs"?\s*$`（结尾锚定＝不带任何附加参数才算守护进程），并排除 `runner.js`。
- **带 pid**：只有"进程在 + 心跳新鲜"时，上一个实例留下的心跳 + 任意活着的进程 = **假健康**，
  该重启时不会重启（实际发生过：空窗一分多钟没人发现）。

## 心跳的含义

心跳**只在长连接认证成功时**才写，之后每 60 秒刷新一次。
所以"心跳停了"＝"连接断了"，而"进程在但心跳旧"正是看门狗要抓的那种故障。

## 日常体检

```cmd
type logs\heartbeat.txt                  :: 时间在 4 分钟内 = 健康
type logs\watchdog.log                   :: 健康时它是空的（安静就是好事）
schtasks /query /tn WecomFastlane        :: 状态 + 上次运行结果应为 0
```

## 改完配置怎么让它生效

```cmd
schtasks /delete /tn WecomFastlane /f
schtasks /create /tn WecomFastlane /tr "wscript.exe //nologo D:\wecom-fastlane\watchdog-hidden.vbs" /sc minute /mo 1 /f /rl LIMITED
```
或者只结束进程、等看门狗在 1 分钟内自动用新配置拉起：

```cmd
powershell -NoProfile -Command "$p=[int](Get-Content D:\wecom-fastlane\logs\fastlane.pid -Raw); Stop-Process -Id $p -Force"
```

## 单实例保护

守护进程启动时会检查：pid 文件指向的实例**还活着**且**心跳新鲜**（<120 秒）→ 直接退出。
避免同一个机器人挂两条长连接（那会导致消息被两边各回一次）。

## 前提

计划任务默认"仅在用户登录时运行"（不需要存密码）。所以**机器要处于登录状态**；
开机但不登录，机器人不会有反应。
