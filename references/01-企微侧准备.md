# 01 · 企微侧准备

## 建机器人

1. 管理员登录 `work.weixin.qq.com` → **智能机器人** → 新建。
   - 菜单名各版本略有差异；认准 **「智能机器人」** 这个词。
   - 如果只看到"自建应用 / 接收消息服务器配置 / 回调 URL"，那是**另一条技术路线**（需要公网入口 + 5 秒被动回复），不是本方案。
2. **接收方式选「长连接」/「WebSocket 长连接」。**
   这是本方案最关键的一次点击 —— 它让机器人由**你的电脑主动连出去**，因此：
   - 不需要公网 IP
   - 不需要域名 / 备案
   - 不需要回调 URL
3. 记下两个值：
   - **botId**：形如 `aibXXXXXXXXXXXXXXXXXXXXXXXX` —— 不是秘密，可以写进配置、可以外发。
   - **secret**：一长串随机字符 —— 是密码。写进本机 `secret.txt`（UTF-8 **无 BOM**、只一行、无多余空格），或用环境变量。
4. **把机器人加入目标群**（群设置 → 添加群机器人）。不加进群，@ 它不会有任何反应。
5. 单聊也能用：使用者直接和机器人对话即可（命令表里 `chats` 为空或未匹配群限制时，单聊默认放行）。

## 采集 userid 与群 ID

这两个 ID 你没法从后台直接抄，但程序会把它们写进日志 —— 所以流程是：

1. 先随便填一个占位值（如 `"unknown"`）让程序跑起来；
2. 让使用者去群里 @ 一次机器人（发任意内容）；
3. 打开 `logs\fastlane.log`，找到这一行：

```
[2026-09-19 12:36:01] 收到消息 chattype=group chat=<群ID>(<群名>) user=<userid> text="订单"
```

- `user=` 后面 → 填进 `allowedUsers`
- `chat=` 后面 → 填进 `allowedChats` 和 `groups`

> 注意：**消息在进白名单判断之前就已经写日志了**。所以白名单为空时，机器人虽然不回应，但 ID 照样能采集到。这是有意设计的：既不响应陌生人，又不妨碍你自己配。

## 常见坑

| 坑 | 现象 | 处理 |
|---|---|---|
| 机器人没加进群 | @ 了完全没反应，日志里也没有"收到消息" | 群设置里添加机器人 |
| 进错后台页面 | 只让填回调 URL | 回到"智能机器人"，别走"自建应用" |
| secret 带 BOM | 报认证失败 / `secret 缺失` | 用 VS Code/Notepad++ 另存为 UTF-8（无 BOM） |
| secret 多了空行 | 同上 | 只保留一行，结尾不要多敲回车 |
| 复用现有 AI 助手机器人 | 群里出现**两条回复**，而且 token 照样在烧 | **另建一个**机器人（见 SKILL.md 硬规则） |
| 群 ID 填错 | 该群不响应，其它群正常 | 从日志里复制，注意别漏字符 |
