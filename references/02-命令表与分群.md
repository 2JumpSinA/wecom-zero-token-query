# 02 · 命令表与分群

## 顶层字段

| 字段 | 含义 | 注意 |
|---|---|---|
| `botId` | 智能机器人 ID | 形如 `aib…`，非秘密 |
| `secretEnv` | 存 secret 的环境变量名 | 默认 `WECOM_FASTLANE_SECRET` |
| `secretFile` | 存 secret 的文件名（相对程序目录） | 环境变量优先于文件 |
| `allowedUsers` | **谁能用**（userid 白名单） | **留空数组＝谁都不响应**（安全默认） |
| `allowAllUsers` | 写 `true` 时**对所有人开放**，忽略 `allowedUsers` | ⚠️ 安全相关：默认关闭。只有在"这个机器人就是给全公司查的、且命令表里全是无害只读查询"时才开 |
| `allowedChats` | **哪些群能用** | 留空＝所有群；建议只列你自己的群 |
| `groups` | 群 ID → 群名/默认品牌 | 只影响日志和帮助文案的可读性，但强烈建议填 |
| `commands[]` | 命令表，见下 | 能力上限 = 这里写了什么 |
| `alerts` | 连续失败告警策略 | `{ "enabled": true, "consecutiveFailures": 3, "cooldownMinutes": 60, "dryRun": false }`：同一命令连续失败 N 次就主动往"出事的那条会话"推一条提醒；冷却期内不重复；成功一次即清零。`dryRun: true` 只写日志不打扰群 |
| `authHints` | 失败回执里的人话提示 | `[{ "match": "<正则>", "hint": "<怎么办>" }]`：命中就把 hint 加进失败回复（`💡 …`）。**配置的规则优先，内置规则兜底**，所以只加一条不会丢掉通用覆盖 |

## 单条命令的字段

| 字段 | 必填 | 含义 |
|---|---|---|
| `id` | ✅ | 内部编号，英文，唯一 |
| `label` | ✅ | 群里回复时显示的名字 |
| `match` | ✅ | **全名**触发词数组，任何允许的群/单聊都能用 |
| `generic` | ⬜ | **通用别名**数组，只在"当前会话里唯一指向一条命令"时生效（多品牌分流靠它） |
| `chats` | ⬜ | 只在这些群可用；空数组＝所有群；**单聊不受此限制** |
| `cwd` / `exe` / `args` | ✅ | 用哪个解释器、在哪个目录、跑什么。路径写双反斜杠 |
| `extract` | ⬜ | `separator`（默认）＝取两条 `====` 之间；`stdout`＝整段输出 |
| `dropLines` | ⬜ | 正则数组，丢掉噪声行（如 `^\[`、`^=== `、`^---\s*第`） |
| `html` | ⬜ | 默认剥 HTML 标签；写 `keep` 则原样保留（几乎不需要） |
| `brandScope` | ⬜ | 写 `"group"` 时，回复前**按本群品牌裁剪正文**（见下） |
| `timeoutMs` | ⬜ | 超时（毫秒），默认 300000 |
| `long` | ⬜ | 标记"这条比较慢"，帮助文案里会提示 |
| `readonly` | ⬜ | 写 `true`：显式声明这条命令只读。用于**消歧**（脚本用"不带 `--send`"表示预演时，机器看不出"缺少参数"，`--check` 会提示未检出预演开关） |
| `builtin` | ⬜ | 内建命令，不跑脚本。目前支持 `"status"`：回进程/连接/心跳/当前任务/最近执行。这类命令**不需要** `exe`/`args` |
| `enabled` | ⬜ | 写 `false` 可临时停用一条 |

## 多品牌 / 多群互不串味（核心用法）

场景：两个群各自关心不同品牌，用户希望在两群里都说「门店」而各出各的。

```json
"commands": [
  { "id": "brandA-shops", "label": "A品牌门店",
    "match": ["A品牌门店"], "generic": ["门店", "营业"],
    "chats": ["<A品牌群ID>"], "...": "..." },

  { "id": "brandB-shops", "label": "B品牌门店",
    "match": ["B品牌门店"], "generic": ["门店", "营业"],
    "chats": ["<B品牌群ID>"], "...": "..." }
]
```

解析顺序（`fastlane.mjs` 里的 `resolveCommand`）：

1. 先按 `match` **精确匹配** —— `A品牌门店` 在任何地方都认（跨群查也用它）；
2. 再按 `generic` 匹配 —— 只有当**当前会话里**唯一一条可用命令带这个别名时才生效：
   - A 品牌群里说 `门店` → 唯一命中 A 品牌那条 → 出 A 品牌
   - B 品牌群里说 `门店` → 出 B 品牌
   - 单聊里说 `门店` → 两条都可用 → 返回"请写明品牌"，不猜
3. 都不命中 → 回帮助（帮助里只列**本群可用**的命令，越界命令不会出现）

**验收入口**：`run-fastlane.cmd --routes` 会把每个群 × 每个触发词的解析结果打出来，联网都不用。改动命令表后**必跑这个**。

## `brandScope: "group"` —— 同一段输出里裁掉别的品牌

场景：**余额**这类命令天然是"多品牌一起查"（一次查四个账号），但它在品牌 A 群里出现品牌 B 的数字就是串味。
`chats` 只能决定"这条命令在这个群能不能用"，决定不了"同一段输出里哪些行该发出去"，所以需要它。

规则（正文按**空行**切区块）：

- 区块里出现了哪个"已知品牌"（= 所有群绑定品牌的并集）→ 就归属哪个品牌
- 沾到**本群品牌**就保留；只沾别的品牌 → 整块丢弃
- **一个品牌都没出现**的区块（标题、说明行）一律保留
- **群没绑品牌（`brands: []`）→ 完全不裁剪**，原样发出
- 裁完为空 → 退回原文（绝不发空消息）
- **单聊不裁剪**（没有群身份）

所以"只想自己看、不需要分品牌"的群，就配 `"brands": []` —— 它会看到完整内容。

## 配置字段之外的验证工具

| 命令 | 用途 |
|---|---|
| `--routes` | 打印**每个群** × 每个触发词的解析结果（含 brandScope 生效的群） |
| `--as-group <群ID>` | 以"某个群的视角"试跑一条命令：会应用该群的品牌裁剪，但**不往群里发** |

## 常见配置错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| JSON 里路径写单反斜杠 | 解析失败或路径错 | `D:\\scripts\\x.py` |
| `exe` 只写 `python` | 计划任务里 PATH 可能不同，找不到解释器 | 写绝对路径 |
| 忘了 `-X utf8` | 中文输出可能乱码 | `args` 里加 `-X utf8`，并确认脚本本身是 UTF-8 |
| `match` 写了但 `chats` 没写 | 命令在所有群都能用（可能无意间开放） | 按需显式限定 `chats` |
| 直接改 `commands.example.json` | 下次更新被覆盖 | 复制成 `commands.json` 再改 |
